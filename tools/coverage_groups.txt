#   STATUS  SELECTOR  why
# STATUS is platform, engine, unused or open (see coverage.py); SELECTOR an address range 0xLO-0xHI or a class
# name (a glob: Gui*), matched against the function's class or the class nearest before it. The first rule that
# matches wins, so ranges go first and narrow class rules before wide ones. A cited function is ported or read
# whatever its rule says.
